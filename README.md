# StockDesk marketing site

Static site for www.stockdeskinventory.com, deployed on Vercel.

- `index.html`, `styles.css`, `main.js`: the landing page
- `privacy.html`, `terms.html`, `404.html`
- `assets/shots/`: screenshots of a demo shop (fictional data, never real customers)

Run locally: `python -m http.server 8080` and open http://127.0.0.1:8080
